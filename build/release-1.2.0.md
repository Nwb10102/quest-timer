## Quest Timer 1.2.0

배포를 다시 Electron exe 로 되돌리고, 탭 막대를 화면 아래로 옮겼습니다.

- 설치해서 쓰는 `Quest Timer Setup 1.2.0.exe` 와 설치 없이 바로 실행하는
  `Quest Timer 1.2.0 portable.exe` 두 가지로 냅니다. .NET Framework 나 WebView2
  런타임을 따로 준비하지 않아도 됩니다.
- 탭 막대가 화면 아래에 떠 있습니다. 타이머를 보는 동안 손이 가는 곳이고,
  아이콘이 함께 붙어 좁은 창에서도 어느 화면인지 알아볼 수 있습니다.
- Inter 글꼴을 앱에 함께 넣었습니다. Windows 판본에 따라 없을 수 있는 글꼴에
  기대지 않으므로 어느 PC에서나 숫자 자리가 흔들리지 않습니다.
- 남은 시간이 1초 줄 때 바뀌는 자리만 숫자가 넘어갑니다. 화면이 가려져 있거나
  동작 줄이기를 켜 두셨으면 넘기지 않습니다.
- Windows 알림이 `Quest Timer` 이름으로 옵니다.
- 새 판이 올라오면 앱이 알아서 받아둡니다. 설치는 직접 누르셔야 하고, 구간이
  진행 중이면 막습니다. 자동 업데이트는 설치본에서만 동작합니다.

## 실행

설치본은 받아서 실행하시면 됩니다. 포터블은 exe 하나만 받아 바로 실행합니다.
Windows 10/11 x64 면 됩니다.

코드 서명은 적용되지 않았습니다. 처음 실행할 때 SmartScreen 경고가 뜨면
`추가 정보` → `실행`을 눌러 주세요.

기록은 `%APPDATA%\Quest Timer\data.json` 에 저장됩니다.

## 1.1.0 (WebView2 판) 을 쓰고 계셨다면

1.1.0 은 기록을 `%APPDATA%\Quest Timer WebView2\data.json` 에 따로 저장했습니다.
이 판은 그 폴더를 읽지 않으므로, 그동안의 기록을 이어서 쓰시려면 그 파일을
`%APPDATA%\Quest Timer\data.json` 으로 복사해 주세요.

1.1.0 의 자동 업데이트는 ZIP 을 찾기 때문에 이 판으로 저절로 넘어오지 않습니다.
위의 exe 를 직접 받아 주세요.

게임 규칙 테스트 33개와 Electron 회귀 검사 49개를 통과했습니다.
