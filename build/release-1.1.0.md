## Quest Timer 1.1.0

WebView2로 실행기를 전환하고 도전과제를 프로필에 통합했습니다.

- 앱 폴더 약 1.07 MiB, 다운로드 ZIP 약 0.35 MiB로 경량화했습니다. PC의 공유 WebView2 런타임과 사용자 캐시는 별도입니다.
- 프로필에서 레벨·경험치·누적 집중·완주 횟수·연속 기록·도전과제를 함께 확인합니다.
- 원형 타이머, 다크 모드, 대기·일시정지 중 잔잔한 블러, 집중 시작 시 패널 자동 접기를 유지합니다.
- 첫 실행 시 이전 Electron 공부 기록을 복사해 가져옵니다. 이전 원본은 보존하며, 이후 두 앱의 기록은 별도로 저장됩니다.
- 최소화 중 완주 알림, +5분 추가, 항상 위에 표시, 기록 백업·복구를 지원합니다.

## 실행

1. `Quest Timer 1.1.0 WebView2.zip`을 다운로드해 전체 압축을 풉니다.
2. 폴더 안의 `Quest Timer.exe`를 실행합니다. DLL과 `www` 폴더도 함께 있어야 합니다.

Windows 10/11 x64, .NET Framework 4.8 이상, Evergreen WebView2 Runtime이 필요합니다. WebView2가 없으면 앱이 Microsoft 공식 다운로드 페이지를 안내합니다.

새 기록 위치: `%APPDATA%\Quest Timer WebView2\data.json`.
종료하면 진행 중 타이머도 종료됩니다. 시스템 알림은 Windows 알림 설정의 영향을 받습니다.

게임 규칙 테스트 32개와 실제 WebView2 동작 검증 31개를 통과했습니다.
코드 서명은 적용되지 않았습니다. SHA-256 체크섬 파일을 함께 제공합니다.
