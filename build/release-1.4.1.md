## 바뀐 것

- **1.4.0에서 앱이 켜지지 않던 문제를 고쳤습니다.** 켜자마자 "A JavaScript error occurred in the main process" 오류가 떴습니다. 1.4.0을 설치하셨다면 앱이 스스로 업데이트할 수 없으니, 아래 설치 파일을 받아 한 번 다시 설치해 주세요. 기록은 그대로 남아 있습니다.
- **다른 창을 보는 동안 작은 위젯이 남은 시간을 보여줍니다.** 구간이 돌아가는 중에 강의나 PDF 같은 다른 창으로 넘어가면 화면 오른쪽 아래에 퀘스트 이름과 남은 시간, 다음 휴식까지 남은 시간이 뜹니다. 끌어서 옮길 수 있고, 누르면 앱이 열립니다. 설정에서 끌 수 있습니다.
- **한글 글꼴을 Pretendard로 바꿨습니다.** 숫자와 영문에 쓰던 Inter와 같은 모양으로 그린 한글이라, 한 줄에 섞여도 어긋나 보이지 않습니다.
- **업데이트한 뒤 처음 켜면 무엇이 바뀌었는지 알려드립니다.** 한 번 확인하면 다음 업데이트 전까지는 다시 뜨지 않습니다.

## 받는 곳

- 설치해서 쓰시려면 `Quest-Timer-Setup-1.4.1.exe`
- 설치 없이 쓰시려면 `Quest-Timer-1.4.1-portable.exe`
